## Bug Reports

Open an issue with:

- the p63-sim and bios version
- what you did, and what happened instead
- the cartridge or a small .p63 file that shows the problem, if you can

Security problems go through private reporting instead (see SECURITY.md).

## Pull Requests

Pull requests are welcome for the emulator, tools, utils/ and games/.
Keep each one to a single change, and make sure `cargo test` and standard
test carts pass.
